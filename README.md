# 🌾 Smart Kisan — All in One Farmer Platform

**Digital platform for farmers** to book procurement slots, complete KYC, track live queue status, and get agricultural advisory — simple, secure, and available in multiple Indian languages.

Built during **SIH Hackathon**.

---

## ✨ Features

- 🏠 **Farmer Dashboard** – Personalized home with services & live updates
- 📅 **Slot Booking** – Book procurement slots at nearby Kisan Seva Kendras
- 🛒 **Procurement Booking** – Full procurement flow with status tracking
- 👤 **Profile & KYC** – Farmer profile management
- 👷 **Operator Panel** – Staff/operator view for managing queues & tokens
- 🤖 **Birju Chatbot** – Friendly AI assistant (apple mascot) for farmer help
- 🌐 **Multi-language** – English + Hindi support
- 🔐 **Authentication** – Firebase Auth (login / signup)
- 📱 **Responsive** – Works on mobile & desktop
- 🎬 **Tutorial Video** – Included for onboarding
